# Starlight Runner

Helper scripts and configurations for running and analyzing STARLIGHT stellar population synthesis models.

## Contents

- `pylight.py`: Python toolkit and parser for STARLIGHT output files.
- `simulate_starlight.py`: Simulation and perturbation analysis for STARLIGHT spectral fitting.
- `CreateMasks.py`, `createMaskStarlight.py`: Scripts for generating spectral masks for STARLIGHT.
- `createGridsStarlight.py`: Grid creation utilities for STARLIGHT runs.
- `ConfigToStarlight`, `StCv04.C99.config`, `StCv04.C99.config_opt`: Configuration files for STARLIGHT.
